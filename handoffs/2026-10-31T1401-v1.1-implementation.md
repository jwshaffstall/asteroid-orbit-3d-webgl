## What changed and why it matters

- **The astronomy is now correct.** Earth was about 94° off: its mean longitude was stored as mean anomaly. The 2013 epoch was hard-coded against data of an unknown date. Planets now come from Standish Table 1 with rates, computed in `scripts/js/astorb-astro.js`, and the worst planet is within 0.074° of Horizons (Saturn). The invented Trojan/Hilda resonance terms are gone.
- **Retrograde and very distant asteroids were wrong in the shipped data.** The old parser read inclinations ≥ 100° and a ≥ 1000 AU one column off, so the old binary contained **zero** objects with i ≥ 100°; the catalog has 160. The new parser uses Lowell's documented columns.
- **New catalog:** Lowell snapshot 2026-10-30, 1,579,394 records, epoch 2026-09-17. `temp/astorb3d.bin` is 37.9 MB and is committed once, per ADR 0004. Next to it, `temp/astorb3d.meta.json` holds the epoch, record count, snapshot sha256, class counts and body elements.
- **The app opens at today's date**, with the date in the status bar and notices outside 1800–2050 and beyond ±100 years. The range is clamped to ±1,000 years, and "Reset Time" is now "Now".
- **Bugs fixed beyond the plan:** the 45 s download timeout, which failed below about 7 Mbit/s; the default "Angular Velocity" color mode, which fed values below mediump's range to the fragment shader; and the screenshot server's `startsWith` path check, which a sibling directory sharing the prefix could bypass.
- **Kepler solver:** 7 iterations, not the plan's "5–6". Six leaves 1.9e-4 rad of error at e = 0.99. The test tolerance is 2e-6 for e ≤ 0.9 and 1e-5 at e = 0.99 (float32 conditioning), both measured on the same float32-reduced M the shader sees.

## Gotchas

- **Something auto-stages new files in this repo,** probably the IDE (`.idea/`, `.junie/`). Check `git status` before committing.
- **`core.autocrlf` is on.** `.gitattributes` now keeps `*.bin` and `*.dat` byte-exact; the parser also accepts CRLF.
- **When the epoch changes,** run `npm run data:refresh`. It regenerates the Horizons fixtures and `data/dwarf-planets.json` for the new epoch; otherwise the accuracy tests and dwarf-planet positions refer to the old one.
- **`node --test tests/`** fails: Node treats the directory as a file. Use `npm test`, which uses the default `*.test.mjs` glob, and `npm run test:e2e`.
- **No `CLAUDE.md` is tracked in the repo,** even though a session loaded one. `AGENTS.md` and `project_context.md` are updated and current. Merging the guidance files into one is Phase 10.
